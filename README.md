# CloudCodeX Windows Bootstrap Cloud E2E fixture

Disposable repository for validating CloudCodeX Windows Bootstrap from a real Codex Cloud environment.
The default branch is source-only. Plugin-owned CI resources are allowed only according to the installed plugin contracts.

Metadata-only README commits may be used to produce a fresh source revision for CI branch-coverage tests; they do not change the Windows test semantics.

Legacy pipeline fixture for CloudCodeX Windows Bootstrap 0.6.6: consolidated Gate 1 (Cloud E2E), Gate 2 (authorization continuity) and Gate 3 (runtime regressions and provider-state reconciliation). README-only marker; AGENTS.md and the Windows smoke test are unchanged.
